# Unity Cable Generator

### FEATURES✨
- Two modes: static and real-time dynamic with physical simulation and collision
- Smooth snapping to surfaces
- Batch management and grouping mechanism to customize many cables at once
- Intuitive user interface and one-click creation for streamlined workflow
- Optimized for game performance

## Installation🌠
1. Download the latest .unitypackage from Release
2. In Unity: Assets → Import Package → Custom Package
3. Select the downloaded file and import
4. To generate cables, simply create an empty object and add CableManager script as component
